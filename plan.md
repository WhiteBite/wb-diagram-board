# План улучшения UI/UX Diagram Board

Этот документ содержит подробный план улучшений для доски диаграмм, основанный на лучших практиках проектирования инструментов для визуального мышления (Miro, Lucidchart, FigJam).

## 1. Навигация и Взаимодействие (Core UX)
- [x] **Space + Drag**: Быстрое панорамирование (Hand Tool) при зажатом пробеле.
- [x] **Zoom to Cursor**: Интуитивный зум в точку, где находится курсор мыши.
- [x] **Alt + Drag**: Быстрое дублирование выбранных узлов при перетаскивании.
- [ ] **Smart Guides (Умные направляющие)**: Визуальные линии при перетаскивании для выравнивания узлов относительно друг друга.
- [ ] **Multi-selection Lasso**: Улучшенная рамка выбора элементов.
- [ ] **Keyboard Shortcuts**: Поддержка стандартных горячих клавиш (Ctrl+C/V/D, Ctrl+Z/Y, Delete).

## 2. Miro-style Quick Creation
- [x] **Quick Add Handle**: Единый элемент для создания связей и новых фигур.
- [x] **Predictive Placement**: Создание новой фигуры на оптимальном расстоянии (120-150px) при клике на "+".
- [x] **Drag-to-Connect**: Возможность вытянуть стрелку из любой стороны узла и при отпускании в пустом месте выбрать тип новой фигуры.
- [ ] **Smart Connection Routing**: Автоматический выбор наиболее чистого пути для линий, обходящий другие узлы.

## 3. Визуальный Дизайн (UI Modernization)
- [x] **Glassmorphism**: Полупрозрачные панели инструментов с эффектом размытия (backdrop-filter: blur).
- [ ] **Smooth Animations**: Плавные переходы при появлении панелей, выборе узлов и создании связей.
- [ ] **Refined Typography**: Использование современных системных шрифтов и улучшенная иерархия текста в узлах.
- [ ] **Color Palette**: Обновление стандартных цветов для лучшей читаемости и эстетики (дизайн-токены).
- [ ] **Grid & Background**: Тонкая, ненавязчивая сетка (dots или lines), которая помогает в позиционировании, но не отвлекает.

## 4. Инструменты Редактирования
- [x] **Contextual Floating Toolbar**: Контекстное меню, которое появляется над выбранным узлом и предоставляет быстрый доступ к стилям.
- [x] **Inline Text Editing**: Редактирование текста прямо в узле с поддержкой Markdown и правильным позиционированием.
- [ ] **Shape Morphing**: Возможность быстро сменить тип фигуры (например, из прямоугольника в ромб) через контекстное меню.
- [ ] **Style Sync**: Возможность копировать и вставлять стили между узлами.

## 5. Производительность и Стабильность
- [ ] **Undo/Redo History**: Полноценная история действий с возможностью отката.
- [ ] **Auto-save**: Сохранение состояния в локальное хранилище или на сервер.
- [ ] **Optimized Rendering**: Минимизация перерисовок при работе с большим количеством элементов.
